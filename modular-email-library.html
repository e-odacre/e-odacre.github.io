Modular Email Library

A modular email production system for building, validating, and exporting branded Klaviyo-ready emails.

Try the interactive demo ↗

Internal production workspace — local coding-agent workflow, with manual HTML handoff to Klaviyo.

Problem

Building branded emails from scratch repeats design and development work. It also makes consistency and production checks harder to maintain across campaigns.

Approach

I separated brand identity, content, and presentation into reusable tokens, components, variants, layouts, sections, recipes, and templates. A Laravel workspace organizes brands, emails, components, recipes, and builds.

Workflow

Campaign brief → Brand & recipe → Agent-assisted build → MJML → Validate → Preview → Export

What I built

  • Reusable components, campaign recipes, themes, and brand systems, including a dedicated SanEcoTec email collection.
  • A brief-to-build workflow: choose a brand, recipe, and style; describe the campaign; generate a prompt; use a local coding agent to produce a structured build.
  • Automatic build discovery, searchable emails, desktop/mobile previews, warnings, downloads, and brand-specific organization.
  • A Nunjucks-to-MJML rendering pipeline with strict compilation and HTML export that preserves Klaviyo template tags.
  • Validation for component schemas, registry constraints, MJML compilation, template tags, image alt text, email size, Gmail clipping warnings, brand references, and draft isolation. Automated tests cover the engine and Laravel integration.

Why it matters

Reusable structures reduce repeated production work, while validation helps catch issues before an email reaches the platform. Campaign content can change without rebuilding the brand system each time.

Technology

Laravel, PHP, Node.js, Nunjucks, MJML, Tailwind, JavaScript, and Vite.

What was produced

Created a reusable workspace for producing validated, branded, responsive email HTML. The output is exported for manual import into Klaviyo; the system does not send campaigns or provide automated Klaviyo delivery. AI assistance comes from a local coding agent, rather than an AI API or SaaS product.
